# 博弈决策台

纯前端、本地优先的结构化博弈分析工作台。实现 PRD v1.0 的全部 V1/P0 功能，并按前端技术方案 v2.0.0 使用 shadcn/ui `dashboard-01`、New York v4 与 Neutral 视觉基线。

## 运行

环境要求：Node.js 20+、pnpm 10+。

```bash
pnpm install
pnpm dev
```

访问 `http://127.0.0.1:3000/cases`。

## 已实现

- 案例库、五类业务模板、案例复制与本地版本快照
- 模型适用性问卷、静态近似和收益尺度边界确认
- 2–4 个参与方、每方 2–5 个策略、最多 625 个策略组合
- 多场景收益录入、置信度、依据、备注和 CSV 导入导出
- 全部纯策略纳什均衡、严格/弱均衡、单边偏离证据与裕度
- 最佳响应、严格/弱支配、帕累托有效、参与约束
- 2×2 非退化效用模型的混合策略均衡
- 基准/保守/乐观/自定义场景与稳健/条件均衡比较
- Markdown 报告导出、浏览器打印/PDF
- 全量 JSON 备份恢复与 IndexedDB 本地持久化

## 数据边界

业务数据只保存在当前浏览器的 IndexedDB，不上传服务器。清理站点数据、更换浏览器或设备可能导致数据丢失，请在关键节点导出 JSON 备份。

模板只创建参与方与策略结构，不自动生成真实业务收益。首次运行提供一个明确标记为“演示案例”的示例，用于验证功能。

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
```

单元测试覆盖囚徒困境、协调博弈、匹配硬币、三参与方、收益并列、参与约束和跨场景稳健性；端到端测试覆盖桌面关键分析路径和移动端侧栏。
